SIMULADOR MASA–RESORTE

Requisitos: Python 3 con Tkinter (incluido habitualmente en Python para Windows).
No requiere descargar paquetes adicionales.

Ejecución:
1. Abre la carpeta que contiene simulador_masa_resorte.py.
2. Haz doble clic sobre el archivo, o abre una terminal allí y escribe:
   python simulador_masa_resorte.py
3. Cambia los deslizadores y presiona «Iniciar».
4. Usa «Pausar» o «Reiniciar» según lo necesites.

Modelo: oscilador horizontal ideal sin fricción ni amortiguamiento,
x(t) = A cos(sqrt(k/m) t) con x(0)=A y v(0)=0.
Los resultados se calculan en unidades del Sistema Internacional.
